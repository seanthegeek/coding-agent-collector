## 2. Transcript files

**Cline, legacy "task" layout** (one directory per task). Root is VS Code `globalStorage/saoudrizwan.claude-dev/` for the extension (`apps/vscode/src/core/storage/disk.ts:190-194`) or `~/.cline/data/` for CLI/JetBrains (`apps/vscode/src/sdk/legacy-state-reader.ts:24-29`); env `CLINE_DATA_DIR` or `CLINE_DIR` override. **Cline, SDK "session" layout** (current, all hosts): `~/.cline/data/sessions/<sessionId>/` (`sdk/packages/shared/src/storage/paths.ts:179-192`) holding `<sessionId>.json` (manifest), `<sessionId>.messages.json`, `<sessionId>.compaction.json` (`sdk/packages/core/src/services/session-artifacts.ts:75-94`); subagent transcripts in the root session dir as `<agentId>.messages.json` or `<agentId>__<teamTaskId>.messages.json` (`:34-57,132-144`). sessionId is `` `${Date.now()}_${nanoid(5)}` `` (`session/services/persistence-service.ts:109`). Hook audit `~/.cline/data/logs/hooks.jsonl` (`hooks/hook-file-hooks.ts:647`).

**Roo Code**: `globalStorage/rooveterinaryinc.roo-cline/tasks/<taskId>/` with `api_conversation_history.json`, `ui_messages.json`, `task_metadata.json`, `history_item.json`; index `tasks/_index.json` (`src/shared/globalFileNames.ts:1-9`). ## 3. Record schemas

## 4. Joins

- Cline/Roo legacy: directory name = `HistoryItem.id`; workspace = Cline `cwdOnTaskInitialization` (`state/taskHistory.json`), Roo `workspace` (`history_item.json` / `_index.json`). `ClineMessage.conversationHistoryIndex` → index into `api_conversation_history.json`. `tool_use.id` ↔ `tool_result.tool_use_id` within the array (rare; most tool traffic is XML text).
- Cline SDK: `messages.json.sessionId` = manifest `session_id` = `sessions.session_id`; workspace = manifest `cwd`/`workspace_root`; `tool_use.id` ↔ `tool_result.tool_use_id`. VS Code merges legacy and SDK lists (`apps/vscode/src/sdk/sdk-task-history.ts:413-424`), stamping `metadata.legacyTask`.
- Kilo: `session.id` ← `message.session_id` ← `part.message_id`; `session.directory` = cwd, `session.project_id` → `project.worktree` (`project/sql.ts:8`); V1 `tool` part carries both call and result in `state`; V2 `assistant.content[].tool.id` likewise.

## 6. Format versions

- Cline: three generations on disk — VS Code globalStorage tasks, `~/.cline/data/tasks` + `state/taskHistory.json`, and `~/.cline/data/sessions/<id>/`. VS Code→file migration of state/secrets is sentinel `__migrationVersion` (`hosts/vscode/vscode-to-file-migration.ts:11-31`); task files are not moved. SDK files carry `version: 1`. Legacy tasks resumed in SDK get `metadata.legacyTask: true`. `sessions.db` has ALTER-based column migrations (`sqlite-db.ts:275-324`).
- Roo: `claude_messages.json` → `api_conversation_history.json` (deleted on read); globalState `taskHistory` → `history_item.json` + `_index.json` `version: 1` (`TaskHistoryStore.ts:320-360`).
- Kilo: JSON `storage/` (two internal migrations, `storage.ts:83-200`) → SQLite via drizzle migrations `packages/core/src/database/migration/2026…` (39 files); `opencode-*.db` renamed `kilo-*.db`; `message`/`part` kept beside `session_message` ("legacy-writer-compat", migration `20260714141136`). Session id prefix `ses`, message `msg`/`msg_`, part `prt` (`schema/src/session-id.ts:5`, `v1/session.ts:17,23`, `session-message.ts:12`).
